## 📖 About This Repository

Welcome to my personal cybersecurity writeups repository.  
Instead of dropping bare flags or copy-pasted answers, every writeup here follows a structured, concept-first approach:

1. **What we did** — Exact commands, configurations, and detection rules used.
2. **Why we did it** — The technical reasoning and architecture behind each step.
3. **What benefit it provides** — How each flag, mode, or rule option helps analysts in real environments.
4. **Complete References** — Organized breakdown tables, quick cheatsheets, and verified lab solutions.
